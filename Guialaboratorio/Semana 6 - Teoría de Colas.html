📖 Introducción a la Teoría de Colas

📚 ¿Qué es la Teoría de Colas?

La Teoría de Colas es una rama de la investigación de operaciones que estudia el comportamiento de sistemas donde los clientes o entidades llegan para recibir algún tipo de servicio. Cuando el servidor está ocupado, los clientes deben esperar en una cola o fila hasta que puedan ser atendidos.

🔤 Notación de Kendall

La Notación de Kendall es un sistema estándar para describir y clasificar sistemas de colas. Se expresa como: A/B/c/K/N/D

Símbolo Significado Valores Comunes
A Distribución de llegadas M (Markoviana/Exponencial), D (Determinística), G (General)
B Distribución de servicio M (Markoviana/Exponencial), D (Determinística), G (General)
c Número de servidores 1, 2, 3, ..., ∞
K Capacidad del sistema Número finito o ∞ (infinito)
N Tamaño de la población Número finito o ∞ (infinito)
D Disciplina de la cola FIFO, LIFO, SIRO, Priority
📝 Nota: Cuando K, N y D no se especifican, se asume: K = ∞, N = ∞, D = FIFO (First In, First Out)

Ejemplos de Notación

M/M/c

Llegadas: Exponenciales

Capacidad: Infinita

M/M/1/K

Llegadas: Exponenciales

Servicio: Exponencial

Servidores: 1

Capacidad: K (limitada)

📊 Modelo M/M/1 y Variantes

🎯 Modelo M/M/1 - El Modelo Fundamental
📐 Características del Modelo M/M/1
  • Primera M: Llegadas siguen un proceso de Poisson (tiempos entre llegadas exponenciales)
  • Segunda M: Tiempos de servicio siguen distribución exponencial
  • 1: Un solo servidor
  • Capacidad: Infinita (no hay límite de clientes en el sistema)
  • Población: Infinita
  • Disciplina: FIFO (First In, First Out)

📋 Supuestos del Modelo

  • ✓ Las llegadas son independientes entre sí
  • ✓ Los tiempos de servicio son independientes entre sí
  • ✓ El sistema opera en estado estacionario
  • ✓ No hay abandonos ni rechazos
  • ✓ El servidor nunca se descompone

🔢 Parámetros Básicos

Símbolo Descripción Unidades
λ Tasa de llegada promedio clientes/unidad de tiempo
μ Tasa de servicio promedio clientes/unidad de tiempo
ρ Factor de utilización (ρ = λ/μ) adimensional (0 < ρ < 1)
1/λ Tiempo promedio entre llegadas unidad de tiempo
1/μ Tiempo promedio de servicio unidad de tiempo

📐 Fórmulas del Modelo M/M/1

1. Factor de Utilización ρ = λ / μ Condición de estabilidad: ρ < 1 (λ < μ)
2. Número Promedio de Clientes en el Sistema L = ρ / (1 - ρ) = λ / (μ - λ) Incluye clientes en cola + cliente siendo atendido
3. Número Promedio de Clientes en Cola Lq = ρ² / (1 - ρ) = λ² / (μ(μ - λ)) Solo clientes esperando (no incluye el que está siendo atendido)
4. Tiempo Promedio en el Sistema W = 1 / (μ - λ) = L / λ Tiempo total: espera + servicio
5. Tiempo Promedio en Cola Wq = λ / (μ(μ - λ)) = ρ / (μ - λ) = Lq / λ Solo tiempo de espera (no incluye servicio)
6. Probabilidad de n Clientes en el Sistema P(n) = (1 - ρ) × ρⁿ para n = 0, 1, 2, 3, ... P(0) = 1 - ρ (probabilidad de sistema vacío)
7. Probabilidad de Esperar P(espera) = P(n ≥ 1) = ρ Probabilidad de que un cliente tenga que esperar

📊 Ejemplo Práctico: Cajero Bancario

🏦 Problema

Un banco tiene un cajero que atiende en promedio 12 clientes por hora (μ = 12 clientes/hora). Los clientes llegan a una tasa promedio de 8 clientes por hora (λ = 8 clientes/hora). Ambos procesos siguen distribuciones exponenciales.

📊 Solución Datos: λ = 8 clientes/hora μ = 12 clientes/hora 1. Factor de utilización: ρ = λ/μ = 8/12 = 0.667 (66.7%) ✓ Sistema estable (ρ < 1) 2. Número promedio en el sistema: L = ρ/(1-ρ) = 0.667/(1-0.667) = 2 clientes 3. Número promedio en cola: Lq = ρ²/(1-ρ) = (0.667)²/(1-0.667) = 1.33 clientes 4. Tiempo promedio en el sistema: W = 1/(μ-λ) = 1/(12-8) = 0.25 horas = 15 minutos 5. Tiempo promedio en cola: Wq = λ/(μ(μ-λ)) = 8/(12×4) = 0.167 horas = 10 minutos 6. Probabilidad de sistema vacío: P(0) = 1 - ρ = 1 - 0.667 = 0.333 (33.3%) 7. Probabilidad de esperar: P(espera) = ρ = 0.667 (66.7%)
📈 Interpretación:
  • El cajero está ocupado el 66.7% del tiempo
  • En promedio hay 2 clientes en el sistema
  • Los clientes esperan en promedio 10 minutos antes de ser atendidos
  • El tiempo total en el banco es de 15 minutos en promedio
  • Hay un 66.7% de probabilidad de tener que esperar

⚖️ Fórmulas de Little

🎓 Ley de Little (Little's Law)

Las Fórmulas de Little son relaciones fundamentales en teoría de colas que conectan el número promedio de clientes en un sistema con el tiempo promedio que pasan en él. Son válidas para cualquier sistema en estado estacionario, independientemente de las distribuciones de llegada y servicio.

📐 Las Tres Fórmulas Fundamentales

1. Ley de Little para el Sistema Completo L = λ × W Donde: L = Número promedio de clientes en el sistema λ = Tasa de llegada efectiva W = Tiempo promedio en el sistema Interpretación: El número promedio de clientes en el sistema es igual a la tasa de llegada multiplicada por el tiempo promedio que pasan.
2. Ley de Little para la Cola Lq = λ × Wq Donde: Lq = Número promedio de clientes en cola (esperando) λ = Tasa de llegada efectiva Wq = Tiempo promedio en cola (esperando) Interpretación: El número promedio esperando es igual a la tasa de llegada multiplicada por el tiempo promedio de espera.
3. Relación entre Sistema y Cola W = Wq + (1/μ) L = Lq + ρ Donde: 1/μ = Tiempo promedio de servicio ρ = λ/μ = Número promedio siendo atendidos Interpretación: El tiempo total es la suma del tiempo de espera más el tiempo de servicio.

🎯 Propiedades de las Fórmulas de Little

🌍
Universalidad

Válidas para cualquier distribución de llegadas y servicios

No requieren supuestos de Poisson o exponencial

⚖️
Estado Estacionario

Solo requieren que el sistema esté en equilibrio

Las tasas de entrada y salida deben ser iguales

🔗
Relaciones

Conectan métricas de cantidad (L, Lq) con métricas de tiempo (W, Wq)

Permiten calcular unas a partir de otras

🎨
Simplicidad

Fórmulas algebraicas simples

Fáciles de aplicar y recordar

📊 Ejemplo de Aplicación

🏪 Problema: Supermercado

En un supermercado, se observa que en promedio hay 15 clientes en el sistema (esperando + siendo atendidos). Los clientes llegan a una tasa de 30 clientes por hora. ¿Cuánto tiempo pasa un cliente en promedio en el supermercado?

📊 Solución usando Ley de Little Datos: L = 15 clientes (número promedio en el sistema) λ = 30 clientes/hora (tasa de llegada) W = ? (tiempo promedio en el sistema) Aplicando L = λ × W: 15 = 30 × W W = 15/30 = 0.5 horas = 30 minutos Respuesta: Un cliente pasa en promedio 30 minutos en el supermercado.
🏥 Problema: Sala de Emergencias

En una sala de emergencias, los pacientes esperan en promedio 45 minutos antes de ser atendidos. La tasa de llegada es de 8 pacientes por hora. ¿Cuántos pacientes hay en promedio esperando?

📊 Solución usando Ley de Little para la Cola Datos: Wq = 45 minutos = 0.75 horas (tiempo promedio en cola) λ = 8 pacientes/hora (tasa de llegada) Lq = ? (número promedio en cola) Aplicando Lq = λ × Wq: Lq = 8 × 0.75 = 6 pacientes Respuesta: Hay en promedio 6 pacientes esperando ser atendidos.
💡 Aplicaciones Prácticas de las Fórmulas de Little:
  • ✓ Estimar tiempos de espera a partir de observaciones de cantidad de clientes
  • ✓ Calcular el número de clientes esperado dado un tiempo de servicio objetivo
  • ✓ Validar modelos de simulación (las fórmulas deben cumplirse)
  • ✓ Dimensionar sistemas (cuántos servidores se necesitan)
  • ✓ Análisis de capacidad y planificación de recursos

⚖️ Análisis de Estabilidad

⚠️ ¿Qué es la Estabilidad de un Sistema?

Un sistema de colas es estable cuando puede procesar a todos los clientes que llegan sin que la cola crezca indefinidamente. En otras palabras, la tasa de servicio debe ser mayor que la tasa de llegada.

📐 Condición de Estabilidad

Condición Fundamental de Estabilidad Para un sistema M/M/1: ρ = λ/μ < 1 Equivalentemente: λ < μ Donde: ρ = Factor de utilización λ = Tasa de llegada μ = Tasa de servicio Si ρ ≥ 1: Sistema INESTABLE (cola crece sin límite) Si ρ < 1: Sistema ESTABLE (cola se mantiene finita)
Para un sistema M/M/c (múltiples servidores): ρ = λ/(c×μ) < 1 Equivalentemente: λ < c×μ Donde: c = Número de servidores

📊 Interpretación del Factor de Utilización (ρ)

Valor de ρ Estado del Sistema Interpretación Acción Recomendada
ρ < 0.5 Subutilizado Servidor ocioso más del 50% del tiempo Considerar reducir capacidad o consolidar servicios
0.5 ≤ ρ < 0.7 Utilización moderada Buen balance entre eficiencia y servicio Rango óptimo para muchas aplicaciones
0.7 ≤ ρ < 0.9 Alta utilización Servidor muy ocupado, tiempos de espera crecientes Monitorear de cerca, considerar capacidad adicional
0.9 ≤ ρ < 1 Saturación Tiempos de espera muy largos, sistema al límite Urgente: agregar capacidad
ρ ≥ 1 INESTABLE Cola crece sin límite, colapso del sistema CRÍTICO: sistema no viable

📈 Comportamiento de las Métricas según ρ

A medida que ρ se acerca a 1:

  • 📈 L y Lq → ∞ (número de clientes crece sin límite)
  • ⏱️ W y Wq → ∞ (tiempos de espera crecen sin límite)
  • ⚠️ Pequeños aumentos en λ causan grandes aumentos en espera
  • 🔴 El sistema se vuelve extremadamente sensible

🔍 Ejemplos de Análisis de Estabilidad

✅ Ejemplo 1: Sistema Estable
Datos: λ = 20 clientes/hora μ = 30 clientes/hora Análisis: ρ = λ/μ = 20/30 = 0.667 Conclusión: ρ = 0.667 < 1 → Sistema ESTABLE ✓ - El servidor está ocupado el 66.7% del tiempo - Hay un 33.3% de tiempo ocioso - Las métricas L, Lq, W, Wq son finitas y calculables - Sistema operando en rango aceptable
⚠️ Ejemplo 2: Sistema en Saturación
Datos: λ = 28 clientes/hora μ = 30 clientes/hora Análisis: ρ = λ/μ = 28/30 = 0.933 Conclusión: ρ = 0.933 < 1 → Sistema ESTABLE pero SATURADO ⚠️ - El servidor está ocupado el 93.3% del tiempo - Solo 6.7% de tiempo ocioso - Tiempos de espera muy largos: L = 0.933/(1-0.933) = 13.9 clientes W = 1/(30-28) = 0.5 horas = 30 minutos - RECOMENDACIÓN: Agregar capacidad urgentemente
❌ Ejemplo 3: Sistema Inestable
Datos: λ = 35 clientes/hora μ = 30 clientes/hora Análisis: ρ = λ/μ = 35/30 = 1.167 Conclusión: ρ = 1.167 > 1 → Sistema INESTABLE ❌ - La tasa de llegada excede la capacidad de servicio - La cola crece sin límite con el tiempo - Las fórmulas de estado estacionario NO APLICAN - El sistema colapsará eventualmente - ACCIÓN CRÍTICA: Rediseñar el sistema completamente * Agregar más servidores * Aumentar la tasa de servicio * Reducir la tasa de llegada * Implementar sistema de citas/reservas

🛠️ Estrategias para Mejorar la Estabilidad

➕
Aumentar Capacidad
  • Agregar más servidores (M/M/c)
  • Aumentar velocidad de servicio (↑μ)
  • Extender horarios de operación
📉
Reducir Demanda
  • Sistema de citas/reservas
  • Distribuir llegadas en el tiempo
  • Incentivos para horas valle
⚡
Optimizar Procesos
  • Automatización de tareas
  • Capacitación del personal
  • Mejora de procedimientos
🎯
Gestión de Prioridades
  • Colas prioritarias
  • Servicio diferenciado
  • Fast-track para casos simples
⚠️ Advertencia Importante:

Nunca diseñes un sistema con ρ muy cercano a 1 (por ejemplo, ρ > 0.9). Aunque matemáticamente sea estable, en la práctica será extremadamente sensible a variaciones y tendrá tiempos de espera inaceptables. Un buen diseño típicamente apunta a ρ entre 0.6 y 0.8.

📊 Métricas de Desempeño

📈 ¿Qué son las Métricas de Desempeño?

Las métricas de desempeño son indicadores cuantitativos que nos permiten evaluar qué tan bien está funcionando un sistema de colas. Nos ayudan a tomar decisiones sobre diseño, capacidad y mejoras del sistema.

📋 Clasificación de Métricas

👥
Métricas de Cantidad

L: Número promedio en el sistema

Lq: Número promedio en cola

Ls: Número promedio siendo atendidos

⏱️
Métricas de Tiempo

W: Tiempo promedio en el sistema

Wq: Tiempo promedio en cola

Ws: Tiempo promedio de servicio

📊
Métricas de Utilización

ρ: Factor de utilización

P(0): Probabilidad de sistema vacío

P(n): Probabilidad de n clientes

💰
Métricas Económicas

Costo de espera: Cw × Lq

Costo de servicio: Cs × c

Costo total: Suma de ambos
